# ProfitBroX

Веб-приложение для отображения торговых сигналов и рекомендаций по лучшим криптоботам для автоматической торговли фьючерсами.

## Функции

- **Торговые сигналы Forex**: Отображение валютных пар, направления торговли и времени входа/выхода
- **Криптоботы для фьючерсов**: Подробная информация о лучших ИИ и автоматических торговых ботах
- **Автоматическое обновление**: Сигналы обновляются каждые 5 секунд
- **Адаптивный дизайн**: Темная тема с зеленым акцентом

## Включенные криптоботы

- **3Commas** - Профессиональная платформа с ИИ
- **TradeSanta** - ИИ-управляемые боты для фьючерсов
- **Pionex** - Биржа с встроенными ботами
- **Bitsgap** - Комплексная платформа с ИИ
- **Cryptohopper** - Облачные боты с машинным обучением
- **HaasOnline** - Продвинутая платформа с ИИ
- **Gunbot** - Настраиваемые боты с ИИ стратегиями
- **Shrimpy** - Автоматизированная торговля и управление портфелем

## Использование

Просто откройте `ProfitBroX_WebApp.html` в веб-браузере.
